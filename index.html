As long as you use the same browser, same browser profile, and same app URL, your data should still be there tomorrow after closing and reopening the browser.

It is stored in browser localStorage, not just temporary page memory.

The things that will make your task data disappear are: using Reset Data, clearing browser/site data, using incognito/private mode, switching browsers or Chrome profiles, opening a different app URL/domain, or browser settings/extensions that auto-clear site storage.

For extra safety, use Export -> Restorable backup every so often. Then even if browser storage gets wiped, you can use Restore to bring the data back.
